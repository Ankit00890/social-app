# Social App Structure Setup

This project uses a MERN stack with a separated folder structure:
- `backend/`: Node.js, Express, MongoDB
- `frontend/`: React (Vite), Tailwind CSS, Framer Motion

## Setup Instructions

### Backend
1. Navigate to `backend/`
2. Run `npm install`
3. Setup `.env` file
4. Run `npm run dev`

### Frontend
1. Navigate to `frontend/`
2. Run `npm install`
3. Run `npm run dev`
